# VolunTrack (ระบบคำนวณชั่วโมงจิตอาสา / SET-Certificate-OCR)

VolunTrack เป็นเว็บแอปพลิเคชันแบบ Single Page Application (SPA) ที่ช่วยอำนวยความสะดวกในการอ่านข้อมูลจากใบเกียรติบัตร (ไฟล์ PDF) ด้วยเทคโนโลยี AI (Gemini API) เพื่อสกัดชื่อหลักสูตร ระยะเวลา และวันที่ออกใบเกียรติบัตร พร้อมทั้งคำนวณเวลาที่ใช้ไปทั้งหมด (ชั่วโมงและนาที) โดยอัตโนมัติ 

## 🌟 ประโยชน์ที่ได้รับ

1. **ประหยัดเวลา:** ไม่ต้องกรอกข้อมูลใบเกียรติบัตรทีละใบด้วยตัวเอง ระบบสามารถอ่านข้อมูลจากไฟล์ PDF ได้ทันทีด้วยความแม่นยำจาก AI
2. **คำนวณเวลาอัตโนมัติ:** ระบบจะนำระยะเวลาจากทุกใบเกียรติบัตรมาบวกกัน และสรุปผลรวมเป็น "ชั่วโมง" และ "นาที" ให้โดยอัตโนมัติ
3. **ใช้งานง่าย:** เป็นไฟล์ HTML ธรรมดา ไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์ที่ซับซ้อน สามารถเปิดใช้งานผ่านเบราว์เซอร์ได้ทันที
4. **จัดเก็บและส่งออกข้อมูลได้:** ข้อมูลจะถูกบันทึกไว้ใน Local Storage ของเบราว์เซอร์ (ไม่หายเมื่อปิดเว็บ) และสามารถกดส่งออกข้อมูลทั้งหมดเป็นไฟล์นามสกุล `.csv` เพื่อนำไปใช้งานต่อใน Excel ได้

## 🛠️ วิธีการติดตั้ง (Installation)

โปรเจกต์นี้ทำงานฝั่ง Client-side (บนเบราว์เซอร์) 100% จึง **ไม่จำเป็นต้องติดตั้งอะไรเพิ่มเติม** 

1. ดาวน์โหลดไฟล์ทั้งหมดในโปรเจกต์นี้ (หรือ `git clone`) ไว้ในเครื่องของคุณ
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (แนะนำ Google Chrome หรือ Microsoft Edge)

## 🚀 วิธีการใช้งาน (How to Use)

เนื่องจากระบบใช้ **Gemini API** ในการอ่านไฟล์ PDF คุณจำเป็นต้องมี API Key ก่อนเริ่มใช้งาน

1. **รับ Gemini API Key:** ไปที่ [Google AI Studio](https://aistudio.google.com/) แล้วทำการสร้าง API Key (ฟรี)
2. **ใส่ API Key ในระบบ:** เปิดไฟล์ `index.html` นำ API Key ที่ได้มากรอกในช่องด้านขวาบนของหน้าเว็บ และคลิกปุ่ม **"บันทึก"** (ระบบจะจำ Key ไว้ในเบราว์เซอร์ให้สำหรับการใช้งานครั้งต่อไป)
3. **อัปโหลดไฟล์:** ลากไฟล์ PDF ของใบเกียรติบัตรมาวางในกรอบ "ลากไฟล์ PDF มาวางที่นี่" (หรือคลิกเพื่อเลือกไฟล์)
4. **รอ AI ประมวลผล:** ระบบจะส่งไฟล์ไปให้ Gemini AI วิเคราะห์ และเมื่อเสร็จสิ้น ข้อมูลชื่อหลักสูตร, เวลา และวันที่จะปรากฏขึ้นมาในรายการด้านล่าง
5. **เพิ่มข้อมูลเอง (หากจำเป็น):** หากมีใบเกียรติบัตรแบบกระดาษหรือต้องการเพิ่มเอง สามารถคลิกปุ่ม **"เพิ่มด้วยตนเอง"** และกรอกรายละเอียดได้
6. **ส่งออกข้อมูล:** เมื่อเพิ่มใบเกียรติบัตรครบถ้วน สามารถคลิกปุ่ม **"ส่งออกข้อมูล (CSV)"** เพื่อนำข้อมูลและเวลารวมไปใช้งานต่อ

## 📝 หมายเหตุ
- ไฟล์ PDF ที่อัปโหลดจะถูกแปลงเป็น Base64 และส่งไปยัง Google API เพื่อทำการประมวลผล โปรดระมัดระวังหากเอกสารมีข้อมูลที่มีความละเอียดอ่อนสูง
- ข้อมูลรายการเกียรติบัตรที่แสดงในหน้าเว็บ จะถูกบันทึกอยู่ในเบราว์เซอร์ของเครื่องนั้น ๆ (Local Storage) หากเปลี่ยนเครื่องหรือเคลียร์ข้อมูลเบราว์เซอร์ ข้อมูลจะหายไป (แนะนำให้ส่งออกเป็น CSV ไว้เสมอ)
